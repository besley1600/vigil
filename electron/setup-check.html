Vigil
A couple of things to set up before we start.
1
Install GitHub CLI
Vigil uses gh to talk to GitHub.
Download from cli.github.com — or run brew install gh on macOS.
2
Authenticate with GitHub
Open a terminal and run:
gh auth login
Follow the prompts to sign in via browser.
