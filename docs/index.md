## What is Vigil?

Vigil is a background agent runtime that lives in your GitHub repo. It runs skills — markdown instruction files — on a cron schedule. Each skill is a focused autonomous task: write an article, fetch top HN stories, monitor a token price, review a PR.

No server. No daemon. If GitHub Actions is up, Vigil is up.

**117 skills** across six categories:

| Category | Skills | What it does |
|----------|--------|-------------|
| Research & Content | `deep-research`, `digest`, `rss-digest`, `paper-digest`, … | Write articles, summarize feeds, surface papers |
| Dev & Code | `pr-review`, `github-monitor`, `auto-merge`, `vuln-scanner`, … | Monitor repos, review PRs, build features |
| Crypto & Markets | `token-alert`, `defi-monitor`, `on-chain-monitor`, … | Track prices, DeFi positions, prediction markets |
| Social & Writing | `write-tweet`, `thread-formatter`, `syndicate-article`, … | Content, social posting, article distribution |
| Productivity | `morning-brief`, `weekly-review`, `goal-tracker`, … | Personal ops and focus |
| Meta / Agent | `heartbeat`, `skill-repair`, `self-improve`, … | Keep Vigil healthy and self-improving |

## Quick Start

```bash
git clone https://github.com/besley1600/vigil
cd vigil && ./vigil
```

Open `http://localhost:5555`, add your Claude API key or OAuth token, pick skills, and push. GitHub Actions handles the rest.
